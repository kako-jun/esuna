# Esuna（エスナ）

**視覚障害者のための音声ファーストWebアプリ**

🌐 **[今すぐ使う → esuna.llll-ll.com](https://esuna.llll-ll.com)**

---

Esunaは、ニュース・ラジオ・Podcast・SNSなどを、音声と9分割グリッドだけで楽しめるWebアプリです。  
名前はファイナルファンタジーの回復魔法「エスナ」から。失明しても今と同じ趣味を楽しめるように、という想いで作られています。

## 主な特徴

- **9分割グリッドUI** — どの画面も同じレイアウト。1番は必ず「戻る」、9番は必ず「画面案内」。
- **完全な音声読み上げ** — すべてのコンテンツを読み上げます。画面を見る必要はありません。
- **キーボード操作対応** — 数字キー1〜9、矢印キー、Enter、Escapeで操作できます。
- **PWA対応** — ホーム画面に追加してオフラインでも使えます。
- **アカウント不要** — URLを開くだけでそのまま使えます。

## 使い方

### 基本操作

| キー | 操作 |
|---|---|
| `1`〜`9` | グリッドの番号を直接選択 |
| 矢印キー | グリッド間を移動 |
| `Enter` | 決定 |
| `Escape` | 読み上げ停止 / 戻る |

### 9分割グリッドの配置

```
┌───────┬───────────────┬───────┐
│   1   │       2       │   3   │
│ 戻る  │   前の項目    │次の項目│
├───────┼───────────────┼───────┤
│   4   │       5       │   6   │
│ 情報  │  主コンテンツ  │アクション│
├───────┼───────────────┼───────┤
│   7   │       8       │   9   │
│ 補助  │    停止       │ 案内  │
└───────┴───────────────┴───────┘
```

どの画面でも同じ配置なので、一度覚えれば迷わず操作できます。

## 開発者向け

### 技術スタック

- **フロントエンド**: Vite + SolidJS + TypeScript + Web Speech API + hls.js
- **バックエンド**: Hono on Cloudflare Workers + TypeScript

### ローカル環境のセットアップ

```bash
git clone https://github.com/kako-jun/esuna.git

# フロントエンド
cd frontend && npm install && npm run dev
# → http://localhost:5173

# バックエンド（別ターミナル）
cd backend && npm install && npm run dev
# → http://localhost:8787
```

### デプロイ

- **フロントエンド**: Cloudflare Pages — `main` ブランチへのプッシュで自動デプロイ
- **バックエンド**: `cd backend && npx wrangler deploy`
