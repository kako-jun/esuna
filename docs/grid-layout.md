# 9マス UI 固定レイアウト規約

最終更新: 2026-05-08

## 目的

全盲ユーザーが「画面が変わっても操作を覚え直さなくてよい」状態にする。
同じ番号を押せば同じ種類の操作が起きる、という絶対座標の約束を全画面に適用する。

## 配置図（テンキー準拠）

```
1  2  3
4  5  6
7  8  9
```

- 左上 (1) から右下 (9) の順でセルを参照する
- 実装上の配列インデックスは 0〜8

## 固定セル（全画面共通・絶対）

| 番号 | 役割 | 説明 |
|------|------|------|
| 1 | 戻る | 常に前の画面に戻る。例外なし |
| 5 | 主対象 | 現在選択中のコンテンツ（タイトル・本文プレビュー・状態）を表示・読み上げる |
| 9 | 画面案内 | `createGuideAction` で生成。全セルの説明を読み上げる |

## 準固定セル（画面タイプごとのテンプレート）

| 番号 | 一覧系 | 本文・再生系 | 設定・ツール系 |
|------|--------|-------------|---------------|
| 2 | 前の項目へ | 前のセクション / 前のエピソードへ | 前の項目へ |
| 3 | 次の項目へ | 次のセクション / 次のエピソードへ | 次の項目へ |
| 4 | 読み上げ / 詳細 | 本文・詳細情報の読み上げ | 情報読み上げ |
| 6 | 主アクション（開く・再生開始・記事一覧へ） | 主アクション（再生・一時停止） | 主アクション（作成・開始） |
| 7 | 補助情報（件数・位置） | 補助情報（位置・番組情報） | 補助情報 |
| 8 | 音声停止 | 音声停止 | 音声停止 |

## 禁止事項

- 1 番を「戻る」以外に使ってはならない
- 5 番を主対象コンテンツ以外（ボタンや操作系）に使ってはならない
- 9 番を `createGuideAction` 以外に使ってはならない
- 8 番に音声停止以外の役割を混在させてはならない

## 音声停止の仕様（#32 参照）

8 番「停止」は `SpeechManager.stop()` を呼ぶ。

- 発話キューを全消去する
- 一時停止ではない（再開機能はまだない）
- 音声メモ・Podcast・ラジオなどの「音声ファイル再生」と「TTS 読み上げ停止」は別操作
  - TTS 停止: 8 番「停止」
  - 音声ファイル停止: 6 番「一時停止」または同等のアクション

## 画面ごとの配置一覧

### 一覧系（前後移動型）

対象: はてな人気エントリー / コメント / 青空文庫一覧 / Podcast 番組一覧 / ラジオ局一覧 / RSS フィード / RSS 記事 / SNS 投稿 / 5ちゃんねる板一覧 / お気に入り / 続きから / 音声メモ / タイマー一覧

| 番号 | 役割 |
|------|------|
| 1 | 戻る |
| 2 | 前の項目 |
| 3 | 次の項目 |
| 4 | 読み上げ |
| 5 | 現在の項目（タイトル等） |
| 6 | 主アクション（開く / 再生 / 記事一覧 / 開始） |
| 7 | 補助情報（件数・位置） |
| 8 | 停止 |
| 9 | 画面案内 |

### 再生系（音声・動画）

対象: ラジオ再生 / Podcast 再生 / 自動再生プレイヤー

| 番号 | 役割 |
|------|------|
| 1 | 戻る |
| 2 | 前のエピソード / 前のコンテンツ |
| 3 | 次のエピソード / 次のコンテンツ |
| 4 | 現在の情報（番組名・タイトル・状態） |
| 5 | 主対象（現在再生中の内容） |
| 6 | 再生 / 一時停止 |
| 7 | 補助情報（位置・残り時間・プレイリスト） |
| 8 | 停止（TTS 停止） |
| 9 | 画面案内 |

**注意**: ラジオ音量操作はセルには配置しない。音量は端末側で制御するか、将来的に設定画面に移す。

### 本文表示系

対象: 青空文庫本文 / はてな記事本文

| 番号 | 役割 |
|------|------|
| 1 | 戻る |
| 2 | 前のセクション |
| 3 | 次のセクション |
| 4 | 本文・詳細読み上げ |
| 5 | 現在のセクション / 本文プレビュー |
| 6 | 主アクション（作品情報・リロード） |
| 7 | 補助情報（位置情報） |
| 8 | 停止 |
| 9 | 画面案内 |

### ツール系（音声メモ・タイマー）

音声メモ・タイマーは一覧系テンプレートを基本とし、6 番に「録音」「タイマー開始/停止」などツール固有のアクションを配置する。

## SNS 画面の特例

SNS は「リロード」と「プラットフォーム切替」が必要なため、次の配置を採用する：

| 番号 | 役割 |
|------|------|
| 1 | 戻る |
| 2 | 前の投稿 |
| 3 | 次の投稿 |
| 4 | リロード |
| 5 | 現在の投稿 |
| 6 | プラットフォーム切替 |
| 7 | 件数・位置 |
| 8 | 停止 |
| 9 | 画面案内 |

「リロード」と「切替」は 4 / 6 に配置し、前後移動は 2 / 3 に戻す。

## 5ちゃんねる画面の特例

5ちゃんねるの板一覧は成立性が未確定のため、現在は「未対応」表示を優先する。
成立確認後に一覧系テンプレートに合わせる。

## はてなブックマーク画面の特例

はてな系は「リロード」をセルに含めていたが、規約上は 2=前、3=次 を優先する。
リロードは 4 番（読み上げとの選択）または削除して自動リロードに変える。
2026-05-08 時点では 4=リロードとし、成立確認後に 4=読み上げに戻す。

コメント画面の 4 番もリロードとする（一覧系テンプレートの「4=読み上げ」の特例）。

## 自動再生プレイヤーの特例

自動再生プレイヤーは「コンテンツ再生の一時停止/再開」と「TTS停止」の両方を管理する。

| 番号 | 役割 |
|------|------|
| 1 | 戻る |
| 2 | 前のコンテンツ |
| 3 | 次のコンテンツ |
| 4 | 現在の情報（タイトル・説明・残り時間） |
| 5 | 主対象（現在再生中の内容） |
| 6 | コンテンツ再生の一時停止 / 再開 |
| 7 | 補助情報（プレイリスト位置・残り時間） |
| 8 | 音声停止（TTS） |
| 9 | 画面案内 |

「コンテンツの一時停止」（プレイリスト進行の停止）と「TTS の停止」（読み上げの停止）は別操作。
8 番は TTS 停止のみ担当し、コンテンツ再生の操作は 6 番が担当する。

## ラジオ再生画面の特例

ラジオ再生画面は特定の局を固定再生するため、前/次局移動（2/3番）は省略する。
2/3番は空セルとする。
音量操作はセルに配置せず、端末の音量ボタンに委ねる。
