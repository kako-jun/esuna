## 近い将来に追加したいもの

### 読み上げ速度プリセット（#10）

0.5 / 0.7 / 1.0 / 1.5 / 2.0 倍のプリセットを追加する。
設定は LocalStorage に保存し、全画面で反映する。

### 初回チュートリアル（#9）

9マスの使い方とキーボード操作を、起動後1回だけ音声で案内する。

### radiko（#8）

Cloudflare Workers の IP は地域制限でブロックされる。
国内固定 IP サーバー（自宅サーバー / VPS 等）を認証中継に置く設計に変更する。
hls.js でのブラウザ直接 HLS 再生は可能。

### 5ちゃんねる スレッド / レス（#17 に含む）

Workers → 5ch は Cloudflare to Cloudflare の IP ブロックで成立しない。
国内固定 IP サーバー中継 + Monazilla 系 UA に設計変更する。

## 中期的に取り組みたいもの

### AI 視覚アシスタント（#18 / #25）

「この画面に何が写っていますか」という疑問に AI が答える機能。
ローカルで動くマルチモーダルモデルを組み込み、プライバシーを守りながら使える設計を目指す。

### PWA 化（#12）

Service Worker によるオフライン対応とバックグラウンド再生。
ホーム画面への追加でアプリに近い体験を提供する。

### IndexedDB 移行（#11）

音声メモの LocalStorage 容量制限（通常 5〜10MB）を解消する。

## 長期的な構想

### Esuna for PC/Mac（Tauri 版デスクトップアプリ）

Web 版の UI をそのまま WebView で流用し、デスクトップ版でしかできないことだけを追加する。
ローカルファイルの読み上げ・管理、Office ファイル操作支援、AI エージェント連携などを想定。

### 多言語・国際対応

読み上げ言語の切り替え、コンテンツソースの地域設定。

### ゲーム

音声中心のテキストアドベンチャー、RPG 要素のある音声ゲーム。

### Esuna Board（質問掲示板）

視覚障害者が気軽に助けを求められる、チャット形式の軽量掲示板。

---

## 大切にしたいこと

機能を増やすことよりも、今ある機能が確実に動くことの方が重要だ。
視覚障害を持つユーザーが「動かなかった」という経験をすると、次に開く気が失せる。
信頼を積み上げるために、地道に品質を高めていく。
